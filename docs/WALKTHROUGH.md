# Panduan penggunaan MAXWASH (maksimal 5 menit)

Daftar akun melalui Registrasi. Akun baru memiliki daftar pesanan/notifikasi kosong; gunakan **Catat Pesanan** untuk membuat catatan lokal. Data disimpan oleh Room dan tidak memerlukan internet. Petunjuk arah membuka peta/browser dan dapat memerlukan koneksi. Panduan ini bukan klaim bahwa video sudah direkam.

| Waktu | Demonstrasi | Rubrik |
| --- | --- | --- |
| 0:00–0:20 | Jelaskan aplikasi customer dan data lokal. Tunjukkan Login/branding teal serta pilihan registrasi. | Theme, local data |
| 0:20–1:10 | Buka Register. Tunjukkan keyboard nomor/email/password. Isi email salah, password pendek, konfirmasi berbeda; submit nonaktif dan error field. Perbaiki semua; register berhasil ke Home. | Form/Input, validation, state |
| 1:10–2:00 | Catat pesanan dengan pilihan layanan/outlet dan berat. Cari ID yang baru dibuat dan gunakan filter Aktif/Selesai. Jelaskan orderId memilih data Room milik akun aktif; pesanan baru ada pada filter Aktif. | List, detail, Room, navigation argument |
| 2:00–2:30 | Pada Order Details, tunjukkan enam tahapan, status Pesanan Diterima dan outlet. Customer tidak dapat mengubah status. | Detail, data consistency |
| 2:30–3:05 | Buka Notifikasi; pilih notifikasi pesanan yang baru dibuat, kembali lihat indikator dibaca. Tandai semua dibaca dan filter belum dibaca. | State, navigation |
| 3:05–3:40 | Buka Lokasi. Pilih outlet dari Room, periksa alamat/jam operasional, lalu buka Petunjuk Arah di aplikasi peta/browser. | External navigation, persistent selection |
| 3:40–4:30 | Buka Profil. Edit nama/nomor/email/alamat; simpan dan lihat perubahan. Ganti parfum, toggle preferensi, simpan. | Free choice, form/state |
| 4:30–4:50 | Kembali Home untuk nama konsisten. Tutup/buka aplikasi untuk menunjukkan profil dan sesi tersimpan. Logout kembali ke Login; Back tidak membuka halaman akun. | Persistent state, back stack |
| 4:50–5:00 | Tampilkan hasil build/tes yang benar-benar tercatat serta nama/kontribusi anggota. | Documentation/deliverables |

Jelaskan perbedaan dari mockup: Register tidak ada screenshot khusus; timeline enam tahap PRD; Login password lokal; lokasi diadaptasi dari Pickup. Profil menggunakan avatar inisial. Data pesanan/notifikasi dibuat melalui akun pelanggan, tanpa akun atau halaman demo.
