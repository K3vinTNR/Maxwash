# Demo UTS MAXWASH (maksimal 5 menit)

Gunakan akun demo untuk enam pesanan contoh. Registrasi membuat akun terpisah dengan daftar kosong; gunakan **Catat Pesanan** untuk membuat catatan lokal. Data disimpan oleh Room dan tidak memerlukan internet. Panduan ini bukan klaim bahwa video sudah direkam.

| Waktu | Demonstrasi | Rubrik |
| --- | --- | --- |
| 0:00–0:20 | Jelaskan aplikasi customer, data lokal dan lingkup UI UTS. Tunjukkan Login/branding teal. | Theme, dummy data |
| 0:20–1:10 | Buka Register. Tunjukkan keyboard nomor/email/password. Isi email salah, password pendek, konfirmasi berbeda; submit nonaktif dan error field. Perbaiki semua; register berhasil ke Home. | Form/Input, validation, state |
| 1:10–2:00 | Pada akun baru, catat pesanan dengan pilihan layanan/outlet dan berat. Logout lalu masuk demo untuk mencari/filter MW-1001 dan MW-1003. Jelaskan orderId memilih data Room milik akun aktif. | List, detail, Room, navigation argument |
| 2:00–2:30 | Pada Order Details, tunjukkan enam tahapan, current status/progres dan outlet. Customer tidak dapat mengubah status. | Detail, dummy consistency |
| 2:30–3:05 | Buka Notifikasi; pilih notifikasi MW-1002, kembali lihat indikator dibaca. Tandai semua dibaca dan filter belum dibaca. | State, navigation |
| 3:05–3:40 | Buka Lokasi. Pilih outlet dari Room, muat ulang data lokal, lalu tampilkan dialog Direction. Jarak tersimpan tetap merupakan data contoh, bukan pengukuran GPS. | Native-feature UI only, persistent selection |
| 3:40–4:30 | Buka Profil. Edit nama/nomor/email; simpan dan lihat perubahan. Perbesar QR visual CUST-001. Ganti parfum, toggle preferensi, simpan. | Free choice, form/state |
| 4:30–4:50 | Kembali Home untuk nama konsisten. Tutup/buka aplikasi untuk menunjukkan profil dan sesi tersimpan. Logout kembali ke Login; Back tidak membuka halaman akun. | Persistent state, back stack |
| 4:50–5:00 | Tampilkan hasil build/tes yang benar-benar tercatat serta nama/kontribusi anggota. | Documentation/deliverables |

Jelaskan perbedaan dari mockup: Register/QR tidak ada screenshot khusus; timeline enam tahap PRD; Login password lokal; lokasi diadaptasi dari Pickup. Peta ilustrasi dan avatar inisial tidak sama dengan aset screenshot.
